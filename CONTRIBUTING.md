# Contributing to Voxel Games

Thanks for contributing! Please follow these ground rules to keep the project organized and easy to work with.

## Asset Management
- All assets must be loaded from a single path: `voxel-games/public/assets/` (with subfolders as needed)

## Code Organization
- **Interfaces**: Create all new interfaces in `src/config/interfaces/interfaces.ts`
- **Types**: Create all new types in `src/config/types/types.ts`
- **Constants**: Create all new constants in `src/config/data/constants.ts`
  - Exception: If a constant is used only in one class, it can live there instead

## Communication
- Keep messages succinct and clear
- Use simple language—avoid jargon when possible
- When submitting work to an AI agent, ask first before it implements anything

## Documentation
- Markdown reports should only be created when explicitly requested
- If you think a report would be helpful, ask first
