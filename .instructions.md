# Development Ground Rules

These rules apply to all development work in this project, including AI agent tasks.

## Asset Management
1. All assets must be loaded from a single path: `voxel-games/public/assets/` (with subfolders as needed)

## Code Organization
2. All new interfaces → `src/config/interfaces/interfaces.ts`
3. All new types → `src/config/types/types.ts`
4. All new constants → `src/config/data/constants.ts` (unless there's a good reason not to—e.g., the constant is specific to one class only)

## Communication & Documentation
5. No markdown reports unless explicitly directed. Always ask if one seems necessary.
6. Be succinct.
7. Use simple language. Assume intelligence but not omniscience—explain things clearly.
8. Always ask before implementing anything, even in agent mode.
